# عبد الرحمن المصري · Portfolio

موقع تعريفي ثابت، عربي وإنجليزي، بمشهد CSS ثلاثي الأبعاد، وضع داكن/فاتح، ونموذج استشارة يجهّز رسالة واتساب تلقائيًا. يعمل بدون خادم أو إعداد بناء: افتح `index.html` مباشرة أو انشره على GitHub Pages أو أي استضافة ملفات.

## الملفات

- `index.html`: الموقع كاملًا، مع الخط والأيقونة والتنسيق والبرمجة مضمّنة.
- `.nojekyll`: يجعل GitHub Pages ينشر الملفات كما هي.

## المميزات

- تخطيط متجاوب للموبايل والكمبيوتر.
- تبديل اللغة (عربي/إنجليزي) واتجاه الصفحة.
- وضع داكن وفاتح بزر في الأعلى، ويحفظ اختيار الزائر، ويتبع إعداد الجهاز أول مرة.
- مشهد مجسم متحرك باستخدام CSS ثلاثي الأبعاد، بدون مكتبات خارجية.
- زر إيقاف الحركة، واحترام إعداد تقليل الحركة في الجهاز.
- نموذج استشارة: الاسم، رقم الهاتف، نوع الموقع، وتفاصيل إضافية. عند الضغط على «تأكيد وإرسال عبر واتساب» تتجمّع البيانات في رسالة جاهزة ويفتح واتساب لإرسالها إلى رقمك.
- فوتر احترافي فيه روابط الموقع ورقم الواتساب.

## تعديل كارت المشروع وإضافة مشروعات

المشروع المضاف «أكاديمية مدار» مثال افتراضي، وليس عملًا لعميل حقيقي. التكلفة ٥٬٠٠٠ جنيه رقم توضيحي قابل للتغيير وليست تسعيرًا ملزمًا. الصورة معاينة فعلية لصفحة العرض المرفقة، وليست صورة موقع منشور.

افتح `index.html` بمحرر نصوص وابحث عن `const PROJECTS`.
كل عنصر `{ ... }` داخل المصفوفة يمثل كارتًا واحدًا:

- `title`: اسم المشروع بالعربية `ar` والإنجليزية `en`.
- `category`: تصنيف المشروع.
- `description`: وصف المشروع باللغتين.
- `tech`: أسماء اللغات والتقنيات. كل اسم يظهر داخل بلوك منفصل.
- `cost`: التكلفة كما تريد عرضها، مع العملة، باللغتين.
- `image`: مسار صورة المشروع، مثل `assets/my-project.jpg`. ضع الصورة في المجلد نفسه وتأكد من تطابق الاسم.
- `imageAlt`: وصف مختصر للصورة باللغتين.
- `sample`: اتركه `true` للمثال. غيّره إلى `false` للمشروعات الحقيقية حتى تختفي ملاحظة المثال والتكلفة التوضيحية.
- `url`: رابط زر «الذهاب إلى المشروع لايف». السطر معلّم بتعليق عربي. استبدل `./demo-academy.html` برابط مشروعك الحقيقي الذي يبدأ بـ `https://`.

الزر الحالي يعمل ويفتح `demo-academy.html` محليًا في تبويب جديد. هذه صفحة هبوط تجريبية مرفقة للعرض فقط، وليست منصة تعليمية بحسابات أو دفع أو خادم. لا تحتاج إنترنت لمعاينتها. عند رفع الملفات كلها للاستضافة سيعمل الرابط النسبي نفسه.

لإضافة مشروع ثانٍ: انسخ العنصر كاملًا من القوس `{` حتى القوس `}`، وضع فاصلة بعد العنصر الأول، ثم ألصق النسخة قبل `];` وعدّل بياناتها. لا تنس نسخ الصورة الجديدة إلى `assets`. يدعم الكود أي عدد من الكروت ويُرقمها تلقائيًا. ترك `url` فارغًا يخفي الزر حتى تضع رابطًا صالحًا.

يعمل المثال مباشرة بفتح `index.html`. عند النشر ارفع مجلد `assets` وملف العرض مع الموقع، وليس `index.html` وحده.

## تعديل النصوص

النص العربي موجود في `data-ar` والنص الإنجليزي في `data-en`. عدّل النص الظاهر داخل العنصر أيضًا ليطابق العربية. نصوص الحقول داخل `data-ar-ph` و `data-en-ph`.

## ملاحظة عن نموذج الاستشارة

النموذج لا يرسل البيانات لأي خادم. هو فقط يفتح واتساب برسالة جاهزة على رقمك، والزائر يضغط إرسال بنفسه من تطبيق واتساب. لو احتجت استقبال الطلبات على بريد أو قاعدة بيانات مستقبلًا، ده هيحتاج خدمة نماذج خارجية أو خادم.
